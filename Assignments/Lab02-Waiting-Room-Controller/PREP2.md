## قسمت ۱ — شمارنده‌ی بالا/پایین جمعیت (کامل)

### ایده به زبان آدمیزاد

می‌خواهیم بدانیم چند نفر داخل اتاق‌اند:

- کسی **وارد** شد (`IN=1`) → شمارش +۱  
- کسی **خارج** شد (`OUT=1`) → شمارش −۱  

شمارش در چهار بیت `Q3 Q2 Q1 Q0` نگه داشته می‌شود (۰ تا ۱۵).

### سیگنال‌های کنترل شمارنده

قبل از خود بیت‌ها، سه سیگنال مشترک ساخته می‌شود:

| سیگنال | فرمول | معنی |
|--------|--------|------|
| `NCLR` | `¬Clr` | ریست فعال‌بالا برای رجیسترها (`Clr=0` یعنی ریست کن) |
| `ENABLE` | `IN ⊕ OUT` | شمارنده فقط وقتی آپدیت شود که **دقیقا یکی** از ورود/خروج رخ دهد |
| `U` | `= IN` | جهت شمارش: `1` = بالا، `0` = پایین |

چرا XOR برای ENABLE؟

- فقط `IN` → شمارش بالا  
- فقط `OUT` → شمارش پایین  
- هر دو هم‌زمان ۱ → `ENABLE=0` → شمارش **ثابت می‌ماند** (ورود و خروج هم‌زمان خنثی)

هر بیت شمارنده یک `Register` است با:

- `clk = Clk`
- `en = ENABLE`  (اگر enable=0، روی لبه‌ی کلاک عوض نمی‌شود)
- `rst = NCLR`

### منطق toggle (مقدار بعدی هر بیت)

شمارنده‌ی باینری بالا/پایین مثل ripple-carry عمل می‌کند، ولی به‌جای رقم نقلی جمع، سیگنال **اجازه‌ی تاگل** داریم.

| سیگنال | فرمول | معنی |
|--------|--------|------|
| `D0` | `¬Q0` | بیت صفر **همیشه** تاگل می‌کند (۰↔۱) |
| `E0` | `Q0 ⊙ U` | آیا بیت ۰ با جهت شمارش همسوست؟ (XNOR) |
| `D1` | `Q1 ⊕ E0` | بیت ۱ فقط وقتی تاگل کند که `E0=1` |
| `E1` | `E0 ∧ (Q1 ⊙ U)` | اجازه‌ی تاگل بیت ۲ |
| `D2` | `Q2 ⊕ E1` | |
| `E2` | `E1 ∧ (Q2 ⊙ U)` | اجازه‌ی تاگل بیت ۳ |
| `D3` | `Q3 ⊕ E2` | |

`D_i` = ورودی بعدی رجیستر بیت i (اگر ENABLE=1 و لبه‌ی کلاک بیاید، `Qi` می‌شود `Di`).  
`E_i` = مثل رقم نقلی: بیت بعدی فقط وقتی اجازه دارد تاگل کند که همه‌ی بیت‌های پایین‌تر با جهت `U` همسو باشند.

مثال ساده — شمارش بالا از ۰:

```
Q = 0000 ، U=1 ، ENABLE=1
D0 = ¬0 = 1  → بعد از لبه: Q = 0001
بعدی: D0=0, E0=(1⊙1)=1 → D1=0⊕1=1 → Q = 0010
...
```

### خروجی Close

```
Close = Q0 ∧ Q1 ∧ Q2 ∧ Q3
```

یعنی وقتی شمارش = `1111` = ۱۵ → اتاق پر است.  
کاملا **ترکیبی** است (فلیپ‌فلاپ اضافه ندارد) و وضعیت لحظه‌ای را نشان می‌دهد.

### موقع ارائه قسمت ۱ چه بگویی

1. شمارنده‌ی ۴بیتی خودساخته با Register، نه Counter آماده.
2. ENABLE = IN XOR OUT؛ U = IN برای جهت.
3. D و E زنجیره‌ی toggle مثل رقم نقلی.
4. Close = AND همه‌ی بیت‌ها = پر بودن.
5. روی عکس مدار، رجیسترهای Q0…Q3 را نشان بده.

## قسمت ۲ — قفل باز شدن در / Open (کامل)

### ایده به زبان آدمیزاد

در نباید فقط وقتی `Ent` فشرده است باز باشد. باید:

1. درخواست معتبر بیاید → در باز شود (`Open=1`)
2. باز **بماند** حتی اگر دکمه رها شود
3. وقتی شخص واقعا رد شد (`IN=1`) → در بسته شود و شمارنده +۱ کند

یعنی `Open` یک **قفل / latch رفتاری** است، نه یک AND لحظه‌ای از `Ent`.

### شرایط باز شدن معتبر

```
LT15     = ¬Close          // هنوز جا هست (کمتر از ۱۵)
EntValid = LT15 ∧ Ent ∧ T  // درخواست معتبر: جا هست + دکمه + وقت مجاز
```

اگر اتاق پر باشد یا `T=0` باشد، `EntValid=0` و در باز نمی‌شود.

### ساخت Dopen (ورودی بعدی رجیستر Open)

```
orr   = EntValid ∨ Open     // ست تازه، یا از قبل باز بوده (فیدبک)
Dopen = orr ∧ ¬IN           // اگر همین حالا IN آمد، ببند
```

یک `Register` جدا برای `Open`:

- `clk = Clk`
- `en = 1` (هر لبه‌ی کلاک نمونه‌برداری می‌کند)
- `rst = NCLR`
- ورودی D = `Dopen`

### رفتار قدم‌به‌قدم

| رویداد | چه می‌شود |
|--------|-----------|
| `Ent` معتبر، `IN=0` | `Dopen=1` → بعد از لبه `Open=1` |
| `Ent` رها شود ولی `Open` از قبل ۱ | فیدبک `orr` روشن می‌ماند → `Open` می‌ماند |
| `IN=1` (شخص رد شد) | `¬IN=0` → `Dopen=0` → `Open` خاموش؛ همان پالس شمارنده را هم +۱ می‌کند |

جمله کلیدی برای TA:  
همان پالس `IN` هم در را می‌بندد هم جمعیت را یکی زیاد می‌کند.

### ریست ناهم‌گام

`Clr=0` → `NCLR=1` → هر پنج Register (۴ بیت شمارنده + Open) **فورا** صفر می‌شوند،  
بدون نیاز به لبه‌ی کلاک (چون `rst` در Logisim ناهم‌گام است).

### موقع ارائه قسمت ۲ چه بگویی

1. Open یک قفل است با فیدبک، نه فقط Ent.
2. فرمول‌های LT15 / EntValid / orr / Dopen را بگو.
3. سناریوی ورود عادی را روی مدار اجرا کن (جدول پایین).
4. بگو ریست async است.

## اگر TA سوال پیچید

- **چرا Counter آماده نه؟** محدودیت آزمایش؛ خودمان با Register + toggle ساختیم.
- **ENABLE چرا XOR؟** فقط یک رویداد خالص؛ هم‌زمانی شمارش را خراب نکند.
- **Open چرا Register جدا؟** باید سطح نگه دارد تا شخص رد شود؛ اگر فقط `Ent` بود با رها شدن دکمه خاموش می‌شد.
- **Clr فعال‌پایین است** → برای پایه‌ی `rst` رجیستر، `NCLR=¬Clr` می‌سازیم.
- **D چیست؟** مقدار بعدی بیت شمارنده؛ روی لبه‌ی کلاک اگر ENABLE=1 در Q می‌نشیند.
