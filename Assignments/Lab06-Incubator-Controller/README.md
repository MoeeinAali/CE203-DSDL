## طراحی

واحد کنترل دیجیتال انکوباتور، شامل **دو ماشین حالت** طبق دو نمودار صورت آزمایش.

| ماژول | نقش |
|--------|------|
| `rtl/main_fsm.v` | ماشین اصلی (`S1`/`S2`/`S3`) → `heater`, `cooler` |
| `rtl/fan_fsm.v` | ماشین سرعت پنکه (`OUT`/`S1`/`S2`/`S3`) → `crs` بر حسب RPS |
| `rtl/tick_gen.v` | پالس نمونه‌برداری یک‌دقیقه‌ای |
| `rtl/seven_seg_decoder.v` | نمایش سرعت روی Seven Segment |
| `rtl/incubator_controller.v` | اتصال همه به هم |

### واسط

| سیگنال | جهت | پهنا | توضیح |
|--------|------|------|--------|
| `Clk` | ورودی | ۱ | کلاک |
| `RstN` | ورودی | ۱ | ریست ناهم‌گام فعال‌پایین |
| `temp` | ورودی | ۸ | دما، علامت‌دار مکمل ۲، `-10..+60` |
| `heater` / `cooler` | خروجی | ۱ | LED عملگرها |
| `crs` | خروجی | ۴ | دور پنکه (`0`/`4`/`6`/`8` RPS) |
| `crs_seg` | خروجی | ۷ | همان مقدار برای Seven Segment |

### آستانه‌ها

| ماشین اصلی | | ماشین پنکه | |
|---|---|---|---|
| `S1→S2` | `T>35` | `OUT→S1` | `T>35` |
| `S2→S1` | `T<25` | `S1→S2` | `T>40` |
| `S1→S3` | `T<15` | `S2→S3` | `T>45` |
| `S3→S1` | `T>30` | `S3→S2` | `T<40` |
| | | `S2→S1` | `T<35` |
| | | `S1→OUT` | `T<25` |

همه‌ی مقایسه‌ها **اکید** هستند (مثلا در دمای دقیقا ۳۵ خنک‌کن روشن نمی‌شود). دمایی که هیچ شرطی را برآورده نکند حالت را **حفظ** می‌کند — همین باند مرده‌ی ۱۵ تا ۳۵ خاصیت پسماند (hysteresis) می‌دهد.

> **نکته‌ی طراحی:** ماشین پنکه با **حالت بعدی** ماشین اصلی گیت می‌شود، نه حالت فعلی. اگر با `cooler` فعلی گیت شود، در همان tick که خنک‌کن خاموش می‌شود پنکه یک قدم اضافه برمی‌دارد و برای یک دوره‌ی کامل، سرعت غیرصفر با خنک‌کن خاموش نمایش داده می‌شود.
