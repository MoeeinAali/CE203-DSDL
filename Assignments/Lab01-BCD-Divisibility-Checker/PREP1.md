## اسکریپت حرف زدن (~۵ دقیقه)

### ۱) یک جمله (۱۵ ثانیه)
مدار **ترکیبی** است (بدون کلاک/فلیپ‌فلاپ). عدد BCD چهاررقمی می‌گیرد و می‌گوید مضرب ۳ هست یا مضرب ۱۱. فقط گیت‌های پایه: AND / OR / XOR / NOT.

### ۲) ایده‌ی ریاضی (۱ دقیقه)
- **مضرب ۳:** چون `10 ≡ 1 (mod 3)` → کافی‌ست ارقام را جمع کنیم:  
  `S = D3+D2+D1+D0` و چک کنیم `S ≡ 0 (mod 3)`.
- برای چک `S` بدون تقسیم: بیت‌های زوج وزن `+1`، فرد وزن `-1` →  
  `P = s0+s2+s4`، `Q = s1+s3+s5` → شرط: `P ≡ Q (mod 3)`.
- **مضرب ۱۱:** چون `10 ≡ -1 (mod 11)` →  
  `A = D0+D2`، `B = D1+D3` → مضرب ۱۱ وقتی  
  `A=B` یا `A+11=B` یا `A=B+11`.

### ۳) ساختار سلسله‌مراتبی (۱ دقیقه)
از پایین به بالا نشان بده:
1. `full_adder` → بلوک پایه
2. `adder4` / `adder5` → زنجیره‌ی full_adder
3. `cmp3` → شرط `P ≡ Q (mod 3)`
4. `eq5` → تساوی دو عدد ۵بیتی
5. `mod3_checker` / `mod11_checker` → مدارهای اصلی
6. `main` → هر دو با هم

### ۴) تست زنده (۲ دقیقه)
مدار `main` را باز کن و سناریوهای پایین را بزن. اگر وقت بود: `./run_tests.sh`.

| سیگنال | چیست |
|--------|------|

### داخل `mod3_checker`

| سیگنال | چیست |
|--------|------|
| `S` | جمع ارقام `D0+D1+D2+D3` (تا ۳۶، ۶ بیت) |
| `s0…s5` | بیت‌های دودویی `S` |
| `P` | جمع بیت‌های زوج: `s0+s2+s4` (۰…۳) |
| `Q` | جمع بیت‌های فرد: `s1+s3+s5` (۰…۳) |
| `cmp3` / `Eq` | ۱ وقتی `P≡Q (mod 3)` یعنی `P=Q` یا `{P,Q}={0,3}` |

### داخل `mod11_checker`

| سیگنال | چیست |
|--------|------|
| `A` | `D0+D2` (۰…۱۸) |
| `B` | `D1+D3` (۰…۱۸) |
| `AP11` | `A+11` |
| `BP11` | `B+11` |
| سه `eq5` | چک `AP11=B`، `A=B`، `A=BP11` |

### بلوک‌های پایه

| بلوک | ورودی → خروجی | نقش |
|------|----------------|-----|
| `full_adder` | `A,B,Cin` → `S,Cout` | جمع ۱بیتی |
| `adder4` | دو عدد ۴بیتی → مجموع ۵بیتی | ripple از ۴×full_adder |

| `eq5` | دو عدد ۵بیتی → `Eq` | تساوی بیت‌به‌بیت + AND |

## سناریو تست دستی در Logisim (`main`)

پین‌های `D3 D2 D1 D0` را با poke تنظیم کن؛ خروجی‌ها: `mult_of_3` و `mult_of_11`.

| عدد | D3 D2 D1 D0 | mod3 | mod11 | برای گفتن |
|-----|-------------|------|-------|-----------|
| `0132` | 0 1 3 2 | ✓ | ✓ | `S=6`، `P=Q=1`؛ `A=B=3` |
| `0133` | 0 1 3 3 | ✗ | ✗ | `S=7`، `P≠Q`؛ `A=4≠B=3` |
| `0012` | 0 0 1 2 | ✓ | ✗ | فقط ۳ (`S=3`؛ `A=2,B=1`) |
| `0022` | 0 0 2 2 | ✗ | ✓ | فقط ۱۱ (`A=B=2`) |
| `0003` | 0 0 0 3 | ✓ | ✗ | فقط ۳ |
| `0000` | 0 0 0 0 | ✓ | ✓ | صفر مضرب هر دو |
