## اصلاً این آزمایش چیست؟ (۳۰ ثانیه اول ارائه)

یک مدار **ترکیبی محض** در Logisim ساخته‌ایم:

- **بدون** فلیپ‌فلاپ، بدون کلاک، بدون ماشین‌حالت
- ورودی: یک عدد **BCD چهاررقمی** (`D3 D2 D1 D0`، هر رقم ۴ بیت، هر رقم بین ۰ تا ۹)
- خروجی: یک بیت که می‌گوید عدد مضرب ۳ هست یا نه (`mod3_checker`)، و مدار مشابه برای مضرب ۱۱ (`mod11_checker`)

محدودیت مهم آزمایش: **فقط گیت‌های پایه**  
`AND` / `OR` / `XOR` / `NOT`  
نه Adder آماده‌ی کتابخانه، نه Comparator آماده، نه تراشه.

مدار سلسله‌مراتبی از پایین به بالا ساخته شده:

```
full_adder  →  adder4 / adder5  →  cmp3 / eq5  →  mod3_checker / mod11_checker  →  main
```

## قسمت ۱ — تشخیص مضرب ۳ (کامل)

### ایده به زبان آدمیزاد

در مدرسه یاد گرفتی: برای مضرب ۳ بودن، **ارقام را جمع کن**؛ اگر جمع مضرب ۳ باشد، خود عدد هم هست.

چرا اینجا هم کار می‌کند؟ چون در مبنای ۱۰:

```
10 ≡ 1  (mod 3)
```

پس هر توان ۱۰ هم `≡ 1` است:

```
N = D3·1000 + D2·100 + D1·10 + D0
  ≡ D3 + D2 + D1 + D0   (mod 3)
```

پس کافی است:

```
S = D0 + D1 + D2 + D3
```

و چک کنیم `S` مضرب ۳ هست یا نه.  
`S` حداکثر `9+9+9+9 = 36` است → در ۶ بیت جا می‌شود.

### مشکل: خود S را چطور بدون تقسیم چک کنیم؟

مدار نمی‌تواند «تقسیم بر ۳» کند. ترفند دودویی:

```
2 ≡ -1  (mod 3)
```

پس وزن بیت‌های `S` یکی‌درمیان `+1` و `-1` است:

| بیت | وزن mod 3 |
|-----|-----------|
| `s0`, `s2`, `s4` (زوج) | +1 |
| `s1`, `s3`, `s5` (فرد) | −1 |

تعریف می‌کنیم:

```
P = s0 + s2 + s4     (جمع بیت‌های زوج، بین ۰ تا ۳)
Q = s1 + s3 + s5     (جمع بیت‌های فرد، بین ۰ تا ۳)
```

آنگاه:

```
S ≡ P − Q  (mod 3)
```

شرط `S ≡ 0` یعنی:

```
P ≡ Q  (mod 3)
```

چون `P,Q ∈ {0,1,2,3}` فقط دو حالت دارد:

1. `P = Q`
2. `{P, Q} = {0, 3}`  (چون `3 ≡ 0`)

همین کار را بلوک `cmp3` انجام می‌دهد.

نکته جالب: خود `P` و `Q` جمع سه بیت تکی‌اند → دقیقاً یک **full_adder**:

```
full_adder(s0, s2, s4) → بیت‌های P
full_adder(s1, s3, s5) → بیت‌های Q
```

### مسیر سخت‌افزاری mod3

1. دو تا `adder4`: `D0+D1` و `D2+D3`
2. یک `adder5`: جمع دو تا مجموع → `S` شش‌بیتی
3. دو `full_adder`: ساخت `P` و `Q`
4. `cmp3`: چک `P ≡ Q (mod 3)` → خروجی `out`

### مثال کامل مضرب ۳ (حفظ کن)

عدد `132` → `D3=0, D2=1, D1=3, D0=2`

```
S = 2+3+1+0 = 6 = 000110₂

بیت‌ها: s5 s4 s3 s2 s1 s0 = 0 0 0 1 1 0

P = s0+s2+s4 = 0+1+0 = 1
Q = s1+s3+s5 = 1+0+0 = 1

P = Q → out = 1   ✓   (132/3 = 44)
```

مثال مخالف `133`:

```
S = 3+3+1+0 = 7 = 000111₂
P = 1+1+0 = 2
Q = 1+0+0 = 1
P ≠ Q → out = 0   ✓
```

### موقع ارائه قسمت ۱ چه بگویی

1. «چون 10≡1 mod 3، جمع ارقام کافی است.»
2. «S را با adder می‌سازیم؛ برای چک بدون تقسیم، بیت زوج/فرد → P و Q.»
3. «cmp3 شرط P≡Q mod 3 را می‌زند.»
4. مثال 132 را ردیابی کن.

## قسمت ۲ — تشخیص مضرب ۱۱ (کامل)

### ایده به زبان آدمیزاد

قانون معروف مضرب ۱۱: **جمع متناوب ارقام**  
(یکی را جمع، یکی را منها).

چرا؟ چون:

```
10 ≡ −1  (mod 11)
```

پس:

```
N ≡ −D3 + D2 − D1 + D0
  ≡ (D0 + D2) − (D1 + D3)   (mod 11)
```

تعریف:

```
A = D0 + D2     (بین ۰ تا ۱۸)
B = D1 + D3     (بین ۰ تا ۱۸)
```

آنگاه `A − B` بین `-18` و `+18` است.  
تنها مضرب‌های ۱۱ در این بازه: `-11`, `0`, `+11`.

پس عدد مضرب ۱۱ است اگر و فقط اگر:

```
A = B          یا
A + 11 = B     یا
A = B + 11
```

### مسیر سخت‌افزاری mod11

1. دو `adder4`: ساخت `A` و `B`
2. دو `adder5`: ساخت `A+11` و `B+11`  
   (عدد ثابت ۱۱ = `01011₂` با Constant تک‌بیتی)
3. سه `eq5`: چک سه تساوی بالا
4. OR سه نتیجه → خروجی `out`

**کم‌کننده نداریم**؛ به‌جای `A−B`، سه مقایسه‌ی تساوی با جمع ۱۱ می‌زنیم.

### مثال کامل مضرب ۱۱

عدد `132`:

```
A = D0+D2 = 2+1 = 3
B = D1+D3 = 3+0 = 3
A = B → out = 1   ✓   (132/11 = 12)
```

عدد `133`:

```
A = 3+1 = 4
B = 3+0 = 3
A≠B ، A+11=15≠3 ، B+11=14≠4 → out = 0   ✓
```

عدد فقط مضرب ۱۱: `022` → `A=B=2` → mod11=1، ولی `S=4` مضرب ۳ نیست.

### موقع ارائه قسمت ۲ چه بگویی

1. «چون 10≡−1 mod 11، جمع متناوب ارقام.»
2. «A و B را می‌سازیم؛ فقط سه حالت ±11 و 0.»
3. «سه eq5 + OR؛ بدون کم‌کننده.»
4. مثال 132 را بگو.

## بلوک‌های پایه (اگر TA پرسید داخل مدار چیست)

| بلوک | کار |
|------|-----|
| `full_adder` | جمع ۱بیتی: `S = A⊕B⊕Cin`، `Cout = majority` |

| `mod3_checker` | مدار اصلی مضرب ۳ |
| `mod11_checker` | مدار اصلی مضرب ۱۱ |
| `main` | هر دو روی ورودی مشترک؛ خروجی‌ها `mult_of_3` و `mult_of_11` |

### ورودی/خروجی اصلی

| سیگنال | چیست |
|--------|------|
| `D0` | رقم یکان (۴ بیت BCD، ۰…۹) |
| `D1` | رقم دهگان |

| `D3` | رقم هزارگان |

### داخل mod3

| سیگنال | چیست |
|--------|------|
| `S` | جمع چهار رقم (۰…۳۶، ۶ بیت) |
| `s0…s5` | بیت‌های دودویی S |
| `P` | جمع بیت‌های زوج |
| `Q` | جمع بیت‌های فرد |
| خروجی `cmp3` | ۱ وقتی P≡Q (mod 3) |

### داخل mod11

| سیگنال | چیست |
|--------|------|
| `A` | `D0+D2` |
| `B` | `D1+D3` |
| `AP11` | `A+11` |
| `BP11` | `B+11` |
| سه `eq5` | `AP11=B` ، `A=B` ، `A=BP11` |

## اگر TA سوال پیچید

- **چرا بدون FSM؟** آزمایش ترکیبی محض خواسته؛ اتحادهای عددی مسئله را به جمع+مقایسه تبدیل می‌کنند.
- **چرا Adder کتابخانه نه؟** محدودیت: فقط گیت پایه.
- **cmp3 دقیقاً چه می‌کند؟** `P=Q` یا `{P,Q}={0,3}`.
- **چرا برای ۱۱ کم‌کننده نداری؟** سه تساوی با `+11` همان کار را می‌کند.
- **BCD یعنی چه؟** هر رقم جدا ۴ بیت است و فقط ۰…۹ معتبر است؛ مدار روی همین بازه تست شده.
