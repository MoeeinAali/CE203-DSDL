### نمایش عدد

```
word = { imag[7:0], real[7:0] }        هر مؤلفه: مکمل ۲ علامت‌دار، -128..+127
```

نتایج **اشباع** می‌شوند نه سرریز. `100 × 100 = 10000` با سرریز عادی به `16` تبدیل می‌شد که هیچ ربطی به پاسخ ندارد؛ با اشباع `127` می‌شود و پرچم `ovf` بالا می‌رود.

### چرا الف و ب یک ماژول‌اند

```
(ar + j·ai)(br + j·bi) = (ar·br − ai·bi) + j(ar·bi + ai·br)
```

ضرب مختلط ۴ ضرب حقیقی و ۲ جمع حقیقی می‌خواهد؛ جمع مختلط ۲ جمع حقیقی دیگر. اگر دو ماژول جدا بودند، سطح بالا **دو** جمع‌کننده می‌داشت. پس هر دو حالتِ کاری یک ماژول‌اند و بهای قید در **زمان** پرداخت می‌شود نه در سطح.

### زمان‌بندی ALU

| کلاک | ضرب‌کننده | جمع‌کننده |
|------|-----------|-----------|
| `M1` | `ar·br` → `t1` | — |
| `M2` | `ai·bi` | `t1 − ai·bi` → **بخش حقیقی** |
| `M3` | `ar·bi` → `t3` | — |
| `M4` | `ai·br` | `t3 + ai·br` → **بخش موهومی** |

جمع‌کننده روی حاصل‌ضربی کار می‌کند که در **همان کلاک** بیرون می‌آید. بدون این هم‌پوشانی ضرب ۶ کلاک بود، با آن ۴ کلاک — بدون هیچ واحد اضافه.

| عملیات | کلاک اشغال |
|--------|-------------|
| `ADD` / `SUB` | ۲ |
| `MUL` | ۴ |

### مجموعه دستورات

```
[31:28] opcode  [27:25] rd  [24:22] rs  [21:19] rt  [18:16] —  [15:0] imm = {imag, real}
```

| کد | دستور | اثر |
|----|--------|------|
| `0` | `NOP` | — |
| `1` | `LDI rd, imm` | `rd ← imm` |
| `2` | `MOV rd, rs` | `rd ← rs` (بدون ALU) |
| `3` | `ADD rd, rs, rt` | `rd ← rs + rt` |
| `4` | `SUB rd, rs, rt` | `rd ← rs − rt` |
| `5` | `MUL rd, rs, rt` | `rd ← rs × rt` |
| `F` | `HALT` | توقف واکشی |

### پایپ‌لاین

```
IF ──► ID ──► EX ──► WB
       ▲       │
       └───────┘  forward (WB → ID)
       ▲       │
       └───────┘  stall  (EX busy یا مبدأ در حال تولید)
```

- مرحله‌ی `EX` **قابل پایپ‌لاین شدن نیست**: یک ضرب‌کننده ⇒ یک حاصل‌ضرب در جریان. ولی `IF`/`ID`/`WB` با آن هم‌پوشانی دارند.
- **ارسال به جلو از `WB` به `ID` اختیاری نیست:** آرایه‌ی ثبات‌ها در لبه‌ی کلاک نوشته می‌شود و خواندنش ترکیبی است، پس بدون این مسیر دستور وابسته مقدار قدیمی را می‌خواند.
- **`halted` با `finished` فرق دارد:** `halted` فقط یعنی واکشی متوقف شد؛ آخرین نتیجه ممکن است هنوز در ثبات `WB` باشد. برای خواندن ثبات‌ها باید منتظر `finished = halted && !ex_v && !wb_v` ماند.

### اندازه‌گیری پایپ‌لاین

| سناریو | کلاک | نتیجه‌گیری |
|---------|------|-------------|
| ۱۶ دستور تک‌کلاکی مستقل | `19` | ≈ ۱ کلاک/دستور ⇒ هم‌پوشانی؛ بدون آن دست‌کم `3×16` |
| ۱۶ ضرب مستقل | `102` | گلوگاه = ضرب‌کننده‌ی مشترک، نه پایپ‌لاین |
| ۱۶ ضرب زنجیره‌ای | `117` | `117 − 102 = 15` = تعداد جفت‌های وابسته |

آخری یعنی قفل داده **دقیقا یک کلاک** برای هر وابستگی هزینه دارد — همان یک کلاکی که تولیدکننده از `EX` به `WB` می‌رود. این تساوی در تست‌بنچ یک شرط دقیق است، نه یک بازه.
